# Example Project (Ralph Orchestrator Variant)

This project folder demonstrates how to run Agent Foundry with `mikeyobrien/ralph-orchestrator`.

- `agents.json` includes one Ralph-family agent (`mikeyobrien/ralph-orchestrator`).
- `ralph.yml` and `PROMPT.md` live at project root and are copied to `/root/` in the VM.
- `.ralph/` is optional but useful for memories, tasks, and diagnostics.

Use this as a base when you want orchestrator-style loops instead of `frankbria/ralph-claude-code`.
